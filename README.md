# Wazah Ahmad Portfolio

A Next.js portfolio with a custom Three.js badge scene, animated star field, project showcase, and responsive layout.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm run start
```

The project deploys to Vercel through the connected `wazahportfolio` GitHub repository.
